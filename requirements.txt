# PlanBench — Python dependencies to clone, install and run.

# ===================================================================
#   CÀI ĐẶT
# ===================================================================
#
#     python3.12 -m venv .venv
#     .venv/bin/pip install --upgrade pip
#     .venv/bin/pip install -r requirements.txt
#
#     cd apps/web && npm install && cd ../..

# Xong. Chạy dự án:  start.bat  (Windows)  hoặc
#                    ./scripts/dev_stack.sh start  (Linux/WSL/macOS)

# ===================================================================
#   FILE NÀY GỒM NHỮNG GÌ
# ===================================================================
#
# Đủ để chạy **toàn bộ** những gì một người mới clone về cần:
#
#   - API FastAPI + WebSocket
#   - Simulator, A*, DWA, benchmark engine
#   - Đăng nhập (OAuth Google/GitHub + dev login)
#   - Lưu trữ SQLite + migration Alembic
#   - Trợ lý AI ở chế độ mock tất định (không cần API key)
#   - Toàn bộ test suite, formatter và linter
#
# **Không** gồm bốn thứ, mỗi thứ có lý do — xem `requirements-optional.txt`:
#
#   PostgreSQL   chỉ cần khi deploy; local mặc định dùng SQLite
#   MLflow       theo dõi thí nghiệm; thiếu thì tự động tắt, không lỗi
#   PPO / RL     torch nặng vài GB, và chỉ dùng khi train
#   LLM thật     chỉ cần khi bạn dán API key vào .env
#
# Thiếu chúng thì tính năng tương ứng giảm chế độ một cách có kiểm soát
# và **báo rõ**, chứ không crash.
#
# ===================================================================
#   VỀ VIỆC GHIM PHIÊN BẢN
# ===================================================================

# thì không còn đo đúng thứ nó tuyên bố đo nữa. Muốn nâng: sửa có chủ ý,

# Ghim nhân CPU trên Windows (CONTRACTS HĐ-7.4). Linux có
# `os.sched_setaffinity` sẵn trong stdlib; Windows KHÔNG, và `hostinfo.py`
# rơi về psutil ở đó. Thiếu nó thì `pin_to_cores` trả None và mọi run trên
# Windows chạy KHÔNG GHIM — G4 đọc độ trễ theo đồng hồ tường, nên cùng một
# stack đo được 59,30 ms không ghim và 16,10 ms khi ghim 2 nhân.
#
# Hệ thống có báo (`affinity_source: inherited` + cảnh báo trên report),
# nên nó suy giảm có tiếng chứ không âm thầm. Nhưng biện pháp bảo vệ thì
# vắng mặt, và đó là điều duy nhất đáng kể.
#
# Chưa từng được khai cho tới 2026-08-12, dù `hostinfo.py` có hẳn một
# comment gọi nó là "a pinned dependency". Nó chạy được suốt vì môi trường
# conda trên máy dev tình cờ có sẵn — một `.venv` dựng đúng theo README
# thì không. Khai vô điều kiện chứ không dùng marker `sys_platform`: một
# marker sẽ để người dùng Windows tự phát hiện ra thiếu gì.
