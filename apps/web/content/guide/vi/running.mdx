Năm cách chạy hệ thống này. Chọn theo việc bạn đang làm, không theo cách
nào "chuẩn" hơn.

<GuideTabs slug="running">

<div>

Bản web đã triển khai — không cài gì, đăng nhập rồi làm theo
[Bảy bước vận hành](/guide/operation).

Đây là đường dành cho người muốn dùng, không muốn dựng.

</div>

<div>

```bash
bash scripts/dev_stack.sh start     # http://localhost:3000
bash scripts/dev_stack.sh status
bash scripts/dev_stack.sh logs
bash scripts/dev_stack.sh stop
```

Script chạy `alembic upgrade head` **trước** khi khởi động API, và in ra
phương thức đăng nhập nào đang bật. Migration lỗi thì nó dừng và báo, chứ
không khởi động API trên một schema cũ — một API chạy được với schema sai
là cách tạo ra dữ liệu phải sửa tay về sau.

Lần đầu cần cài dependency: Python 3.12 và Node 20 trở lên.

</div>

<div>

Chỉ API, không cần bash:

```
.venv\Scripts\python.exe scripts\serve.py --reload --migrate
```

<Callout kind="trap">

**Đừng gọi thẳng `python -m uvicorn planbench_api.main:app`.** Dự án
không được cài đặt như một package, nên các thư mục dưới `packages/` và
`services/` chỉ vào `sys.path` khi có thứ gì đó đặt chúng vào.
`serve.py` đọc danh sách đường dẫn từ `pyproject.toml` — đúng danh sách
mà pytest dùng — rồi mới khởi động.

</Callout>

</div>

<div>

Một trình cài đặt, một máy, một người. Không cần Docker, Node hay Python
cài sẵn — bản dựng mang theo trình thông dịch của nó.

Dữ liệu nằm dưới `%LOCALAPPDATA%\PlanBench`: cơ sở dữ liệu, artifact,
bản đồ, profile, và tệp `.env` giữ tài khoản cục bộ cùng khoá API.

Windows SmartScreen sẽ cảnh báo nhà phát hành không rõ — trình cài đặt
chưa được ký số.

Khoá API dán ở trang cài đặt, không sửa tệp.

</div>

<div>

Mở `/docs` để thử trực tiếp từ trình duyệt, hoặc gọi bằng `curl`:

```bash
curl -X POST http://localhost:8000/api/v1/decisions \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "task_profile_id": "open_hall_v2",
    "candidates": [
      {"stack": "astar+dwa", "local_config": "dwa_coarse"},
      {"stack": "astar+dwa", "local_config": "dwa_balanced"}
    ],
    "episodes": 30
  }'
```

Trả `201` kèm `id`; đọc kết quả bằng `GET /api/v1/decisions/<id>`.

Đường này hợp khi cần xếp hàng nhiều phép so bằng script. Nó đi qua **đúng
bộ cổng và đúng phép so** như giao diện — không có đường tắt nào ở đây.

</div>
