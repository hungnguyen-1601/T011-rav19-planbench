# assets/

Hình ảnh và tài nguyên tĩnh cho bộ tài liệu Gate G1.

Hiện chưa có file nào: mọi sơ đồ trong bốn deliverable đều viết bằng
Mermaid trong chính file Markdown và được GitHub render trực tiếp.

Quy ước khi thêm file:

- Tên file: chữ thường, nối bằng gạch ngang, có tiền tố số của tài liệu
  dùng nó, ví dụ `03-dashboard-desktop.png`.
- Chèn từ tài liệu cha bằng đường dẫn tương đối tới thư mục này.
- Luôn có alt text mô tả nội dung.
- Không đưa vào ảnh chứa token, email cá nhân hay đường dẫn máy cá nhân.
- Kích thước dưới 500 KB.
